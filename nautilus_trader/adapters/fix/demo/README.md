# Wind QuickFix 交易对接程序 (A股)

本项目基于 **QuickFix** 协议实现与 **Wind (万得)** 交易通道的对接，专门用于 **QFII** 模式下的中国国内 A 股自动化交易。

---

## 🌟 功能特性

* **核心交易**: 支持 A 股的 **下单 (New Order)** 与 **撤单 (Order Cancel)** 动作。
* **数据查询**:
    * **持仓**: 实时获取账户持仓明细。
    * **成交**: 跟踪当日已成单信息。
    * **委托**: 维护当前未成交/已提交的委托状态。
    * **资金**: 查询可用资金、资产净值等。

---

## 📂 项目结构与入口

### 1. 运行入口
| 文件名 | 用途 | 备注 |
| :--- | :--- | :--- |
| `wind_daily_real.py` | **生产环境入口** | 连接真实交易通道，需谨慎操作 |
| `test_daily_test.py` | **自动化测试** | 用于功能验证与联调 |
| `daily_real_wind.py` | **测试环境脚本** | 基础测试逻辑实现 |

### 2. 配置文件
* `wind_fix_config.cfg`: FIX 引擎连接配置（Session、HeartbtInt、DataDictionary 等）。
* **账户配置**:
    * **测试环境**: 账号信息维护在 `test_daily_test.py` 与 `daily_real_wind.py` 中。
    * **真实环境**: 账号信息维护在 `wind_daily_real.py` 中。

## 🛠️ 快速开始

1. **环境准备**:
   确保 Python 环境中已安装 `quickfix` 库。

2. **配置修改**:
   根据所在环境，在对应的 `.py` 文件中更新 `User/Password`。

3. **启动程序**:
   ```bash
   # 测试环境启动
   python test_daily_test.py
   
   # 生产环境启动
   python wind_daily_real.py
